# Sea Scout · โฆษณาสปอนเซอร์แบบบริการตัวเอง · r14.15.75

## หน้าตาในแอป
- **แถบล่าง (สปอนเซอร์):** อยู่เหนือแถบเมนูบนหน้าแผนที่ แผนที่ย่อลงให้พอดี ไม่ทับกัน
  - แบนเนอร์ที่จ่ายเงินแล้วสลับกันรูปละ 10 วินาที (ตั้งได้)
  - ถ้ายังไม่มีผู้ลงโฆษณา จะแสดงการ์ด "📣 ร้านของคุณแสดงตรงนี้ได้ · ลงโฆษณา ›" ที่พาไปหน้าลงโฆษณา
  - แสดงกับผู้ใช้ทุกคน
- **แถบบน (Google):** เว้นพื้นที่ไว้แล้ว แต่ซ่อนอยู่จนกว่าจะตั้ง AdMob (แอป) หรือ AdSense (เว็บ)

## ขั้นตอนของร้านค้า (ทำเองทั้งหมดที่ https://seascout.apisit-chaikham.workers.dev/advertise.html)
1. กรอกชื่อร้าน ลิงก์ร้าน (https) อีเมล และอัปโหลดรูป
   - ระบบย่อและครอปรูปเป็น 1200×240 (5:1) ให้เอง พร้อมแสดงตัวอย่างในกรอบแอป
2. ยอมรับกฎ แล้วกดส่ง ระบบตรวจอัตโนมัติภายในไม่เกิน 30 วินาที
3. ถ้าผ่าน จะขึ้นปุ่ม **ชำระ 5,000 บาท · แสดง 30 วัน** แล้วพาไปหน้าจ่ายเงินของ Stripe
4. จ่ายเสร็จ โฆษณาขึ้นแอปทันที (ภายใน 2 นาที)
5. ร้านได้อีเมลพร้อมลิงก์หน้าสถานะส่วนตัว ในหน้านั้นดูจำนวนครั้งที่แสดง จำนวนคลิก วันหมดอายุ และต่ออายุได้
   - การต่ออายุบวกเวลาต่อจากวันหมดอายุเดิม
   - มีอีเมลเตือน 3 วันก่อนหมดอายุ

## การตรวจอัตโนมัติ (ไม่ผ่านข้อใดข้อหนึ่ง = ไม่รับ และแจ้งเหตุผลเป็นภาษาไทย)
1. **คำต้องห้าม** ในชื่อร้าน ข้อความ และลิงก์:
   - พนัน: บาคาร่า สล็อต คาสิโน แทงบอล หวยออนไลน์ UFABET ฯลฯ
   - เนื้อหาผู้ใหญ่
   - เงินกู้นอกระบบ ยาเสพติด ปืนเถื่อน บัญชีม้า
2. **หน้าเว็บของลิงก์:**
   - ต้องเปิดได้และเป็น https
   - ข้อความในหน้าต้องไม่ใช่เว็บพนันหรือเว็บผู้ใหญ่
   - ลิงก์ Facebook/Shopee/Lazada/LINE/TikTok/Instagram อ่านหน้าไม่ได้เพราะเว็บกันบอท จึงรับโดยไม่อ่านหน้า แต่ยังผ่านการตรวจข้ออื่นทั้งหมด
3. **Google Safe Browsing:** ตรวจว่าเป็นเว็บมัลแวร์หรือหลอกลวงหรือไม่ (ต้องใส่คีย์ ถ้าไม่ใส่จะข้ามข้อนี้)
4. **AI ของ Cloudflare:** ดูรูปแบนเนอร์และข้อความ แล้วตัดสินว่าผิดกฎหรือไม่ (ฟรี 10,000 neurons ต่อวัน)
   - ถ้า AI ล่ม ระบบลองใหม่ทุก 30 นาที
   - ครบ 3 ครั้งแล้วยังไม่ได้ จะตัดสินด้วยข้อ 1–3 อย่างเดียว และบันทึกไว้ในหน้าแอดมิน
5. **ระหว่างแสดง:** ตรวจลิงก์ซ้ำทุก 7 วัน ถ้าร้านเปลี่ยนหน้าเว็บเป็นพนันหลังผ่านการตรวจ ระบบจะระงับทันทีและแจ้งร้านทางอีเมล (ตามกฎที่ร้านยอมรับ: ไม่คืนเงิน)

> ระบบอัตโนมัติจับไม่ได้ 100% แนะนำให้เปิดแท็บ **โฆษณาสปอนเซอร์** ในหน้าแอดมินดูเป็นระยะ กด "ดูรูป" ได้ทุกโฆษณา และ "นำออก" ได้ทันทีพร้อมใส่เหตุผลที่ร้านจะเห็น

## หน้าแอดมิน → แท็บ "โฆษณาสปอนเซอร์"
- สรุปจำนวนโฆษณาที่แสดงอยู่ จำนวนที่รอชำระ และรายได้ 30 วัน
- ตั้งค่า (เจ้าของบัญชีเท่านั้น): ราคา (ตอนนี้ 5,000 บาท), จำนวนวัน (30), จำนวนสูงสุดที่แสดงพร้อมกัน (0 = ไม่จำกัด), เวลาสลับรูป (10 วินาที)
- ทุกโฆษณาทำได้: ดูรูป, ดูผลตรวจแต่ละข้อ, นำออก, คืนสถานะ, ตรวจใหม่, เพิ่มวัน (ชดเชยให้ร้าน)
- ปิดทั้งระบบได้ที่ เปิด/ปิดฟังก์ชัน → `sponsor_ads`

## สิ่งที่คุณต้องตั้งค่า (ใส่เองใน Cloudflare → Worker seascout → Settings → Variables and Secrets)

### 1. Stripe (จำเป็นสำหรับรับเงิน)
1. สมัคร https://dashboard.stripe.com ประเทศไทย แล้วยืนยันตัวตนและบัญชีธนาคารตามขั้นตอนของ Stripe
2. เปิดวิธีจ่ายใน Settings → Payment methods: **Cards** และ **PromptPay**
3. Developers → API keys → คัดลอก **Secret key** มาใส่เป็น `STRIPE_SECRET_KEY` (ชนิด Secret)
   - ทดลองก่อนด้วย `sk_test_…` ได้
4. Developers → Webhooks → Add endpoint:
   - URL: `https://seascout.apisit-chaikham.workers.dev/api/v1/sponsor/stripe`
   - Events: `checkout.session.completed` และ `checkout.session.async_payment_succeeded`
   - คัดลอก **Signing secret** (`whsec_…`) มาใส่เป็น `STRIPE_WEBHOOK_SECRET` (ชนิด Secret)

### 2. Google Safe Browsing (แนะนำ, ฟรี)
Google Cloud Console → เปิด "Safe Browsing API" → สร้าง API key → ใส่ `SAFE_BROWSING_KEY` (ชนิด Secret)

### 3. อีเมลแจ้งร้าน
ใช้ Resend ตัวเดียวกับอีเมลยืนยันสมาชิก (`RESEND_API_KEY` และ `EMAIL_FROM`) ถ้ายังไม่ตั้ง ร้านยังดูสถานะได้จากหน้าเว็บ แต่จะไม่ได้รับอีเมล

### 4. AI
ระบบผูก Workers AI ให้แล้ว (`"ai": { "binding": "AI" }` ใน wrangler.jsonc) ใช้รุ่น `@cf/google/gemma-4-26b-a4b-it` ถ้า Cloudflare เลิกให้บริการรุ่นนี้ ให้ใส่ชื่อรุ่นใหม่ใน `SPONSOR_AI_MODEL`

## ภาระต่อแพ็กเกจฟรี
- แอปขอรายการโฆษณา 1 ครั้งต่อ 30 นาทีต่อเครื่อง
- รูปโหลดครั้งเดียวแล้วเก็บไว้ในเครื่อง
- ยอดการแสดงนับในเครื่องแล้วส่งครั้งเดียวต่อการเปิดแอป
- คลิกนับผ่าน /sponsor/go
- รูปเก็บใน D1 ได้สูงสุด 300 KB ต่อรูป (รูปจริงหลังย่อประมาณ 20–80 KB)

## เรื่องควรรู้
- ร้านซื้อโฆษณาผ่านหน้าเว็บ ไม่ได้ซื้อในแอป จึงไม่ติดกฎการชำระเงินของ Google Play/App Store
- ถ้าต้องออกใบกำกับภาษี (เมื่อจดภาษีมูลค่าเพิ่มแล้ว) ต้องทำเพิ่มภายหลัง ใบเสร็จของ Stripe ไม่ใช่ใบกำกับภาษีไทย
