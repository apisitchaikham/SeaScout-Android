# Sea Scout · ร้านตามประเทศ (ตัวกลาง) · r14.15.74

## ทำอะไร
ผู้ใช้แต่ละประเทศจะเห็นปุ่ม **"🔎 ค้นหาใน <ร้าน>"** ใต้ชนิดปลาแต่ละตัวในหน้าวิเคราะห์ ร้านที่ขึ้นคือร้านที่คนในประเทศนั้นใช้มากที่สุด
- ระบบรู้ประเทศจากอินเทอร์เน็ตของผู้ใช้ (Cloudflare) ซึ่งตรงกับประเทศที่ผู้ใช้สั่งของและรับของ
- ปุ่มพาไปหน้าค้นหาของร้านนั้น ด้วยคำค้นอุปกรณ์ที่ตรงกับปลาตัวนั้น เป็นภาษาของร้าน ผ่านลิงก์ Affiliate ของเรา
- สินค้าที่มีรีวิวจริง (Shopee/AliExpress API) ยังขึ้นก่อน ส่วนปุ่มร้านจะต่อท้าย สูงสุด 3 ร้าน (ร้านละ 1 ปุ่ม)
- ปุ่มร้านจะไม่แสดงดาวหรือยอดขาย เพราะเครือข่ายไม่ได้ให้ข้อมูลนี้ ระบบไม่แต่งตัวเลขขึ้นเอง

| ประเทศ | ร้าน (ลำดับ) | เครือข่าย |
|---|---|---|
| ไทย, มาเลเซีย, ฟิลิปปินส์, เวียดนาม, สิงคโปร์ | Shopee → Lazada | Involve Asia |
| อินโดนีเซีย | Shopee → Lazada → Tokopedia | Involve Asia |
| สหรัฐฯ, แคนาดา, อังกฤษ, เยอรมนี, ฝรั่งเศส, อิตาลี, สเปน, เนเธอร์แลนด์, สวีเดน, โปแลนด์, ญี่ปุ่น, ออสเตรเลีย, ซาอุฯ, UAE, อินเดีย | Amazon | Amazon Associates |
| เม็กซิโก, บราซิล | Mercado Libre → Amazon | Admitad / Amazon |
| อาร์เจนตินา, โคลอมเบีย, ชิลี | Mercado Libre | Admitad |
| ประเทศอื่น | สินค้า AliExpress (ส่งได้เกือบทั่วโลก) | AliExpress API |

แก้ได้ทั้งหมดในหน้าแอดมิน แท็บ **"ร้านตามประเทศ"**: ลำดับร้าน, เปิด/ปิดร้าน, ลิงก์หน้าค้นหา, เลขโปรแกรม และคำค้นของแต่ละภาษา

## ทำไมเป็น "ปุ่มค้นหาในร้าน" ไม่ใช่การ์ดสินค้า
API ของ Involve Asia และ Admitad มีแค่รายชื่อร้าน (offers/โปรแกรม) กับตัวสร้างลิงก์ Affiliate (deeplink) ไม่มีระบบค้นหาสินค้า ส่วนไฟล์สินค้า (datafeed) ใหญ่เกินกว่าจะประมวลผลในแพ็กเกจฟรีของ Cloudflare (CPU 10 ms ต่อครั้ง) ระบบจึงสร้างลิงก์ไปหน้าค้นหาของร้านแทน ร้านจะแสดงสินค้าที่ขายดีและรีวิวดีให้ผู้ใช้เลือกเอง และเรายังได้ค่าคอมเหมือนเดิม

## งานตั้งเวลา
- ทุก 30 นาที ทำลิงก์ให้ **1 ร้าน** ครั้งละไม่เกิน 6 ลิงก์ (ร้านละ 10 ลิงก์ ตามประเภทอุปกรณ์) ทำครบทุกร้านภายในประมาณ 1–2 วัน
- ลิงก์ที่ทำแล้วจะต่ออายุทุก 60 วัน
- Involve Asia จำกัดไว้ที่ 1,000 ลิงก์ต่อ 30 วัน เราใช้ประมาณ 130 ลิงก์
- ภาระต่อรอบ: คำขอออกไปข้างนอกไม่เกิน 8 ครั้ง และเขียน D1 ประมาณ 20–30 แถว

## ตั้งค่า (คุณใส่คีย์เองใน Cloudflare → Worker seascout → Settings → Variables and Secrets)

### Involve Asia (Shopee/Lazada/Tokopedia ในอาเซียน)
1. รอบัญชีได้รับอนุมัติ
2. Profile → Tools → API → **Request API Key** (เขาตรวจภายใน 48 ชั่วโมงทำการ)
3. ใส่ `INVOLVE_API_KEY` และ `INVOLVE_API_SECRET` (ทั้งสองค่าเป็นชนิด Secret)
4. **ต้องสมัครเข้าร่วม (Apply) ร้าน Shopee และ Lazada ของแต่ละประเทศในหน้า Offers** ก่อน ระบบจะใช้ได้เฉพาะร้านที่สถานะเป็น Approved ถ้ายังไม่ได้เข้าร่วม แอดมินจะขึ้นว่า "ยังไม่ได้เข้าร่วมร้านนี้ในเครือข่าย"

### Admitad (Mercado Libre ในละตินอเมริกา)
1. รอ ad space Sea Scout เปลี่ยนเป็นสถานะ **Active**
2. เข้าร่วมโปรแกรม Mercado Libre ของประเทศที่ต้องการ (ถ้า Admitad มีโปรแกรมนั้น)
3. Settings → API and apps → **Show credentials** แล้วใส่ `ADMITAD_CLIENT_ID` และ `ADMITAD_CLIENT_SECRET` (ชนิด Secret)
4. ใส่ `ADMITAD_WEBSITE_ID` = เลข ad space ของ Sea Scout (ชนิด Text)

### Amazon Associates (ทำทีหลังได้)
ใส่ `AMAZON_TAGS` เป็น JSON ของ tracking id แต่ละประเทศ เช่น `{"US":"seascout-20","GB":"seascout-21"}` ประเทศที่ไม่มี tag จะไม่แสดงปุ่ม Amazon

### เปิดใช้
หน้าแอดมิน → เปิด/ปิดฟังก์ชัน → `market_links` → เปิด แล้วไปแท็บ **ร้านตามประเทศ** กด "ทำลิงก์" ทีละร้านเพื่อดูผลทันที

> ก่อนเปิดใช้จริง ผมจะตรวจคำตอบจริงจาก Involve Asia/Admitad ครั้งแรกเทียบกับรูปแบบที่เขียนไว้ เพราะเอกสารของเครือข่ายไม่ได้ระบุชื่อทุกช่องข้อมูล
