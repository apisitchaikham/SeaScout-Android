# ร้านค้าอัตโนมัติ (r14.15.68)

ระบบหาสินค้าและใส่ลิงก์ Affiliate ให้เองทั้งหมด แอดมินไม่ต้องพิมพ์ลิงก์

## ทำงานยังไง
1. **คำค้น**: แต่ละประเภทการตก (หมึก, ปลาผิวน้ำ, ปลาหน้าดิน ฯลฯ) มีคำค้นของตัวเองในตาราง `shop_queries` (Shopee ภาษาไทย, AliExpress ภาษาอังกฤษ) แอดมินแก้คำค้นได้ในแท็บ "สินค้าอัตโนมัติ"
2. **ค้นหา**: Cron ของ Cloudflare รันทุก 30 นาที ครั้งละ 1 คำค้น (ใช้ API 1 ครั้ง เพื่อให้อยู่ในแผนฟรี) จึงรีเฟรชครบ 22 คำค้นในราว 11 ชั่วโมง
3. **คัดสินค้า**: ใช้ได้เฉพาะข้อมูลจาก API ทางการของเครือข่าย ไม่ดึงข้อมูลจากหน้าเว็บ (scraping) และไม่เดาค่าใด ๆ
   - ตัดทิ้งถ้า: ไม่มีคะแนนรีวิว, ไม่มียอดขาย, ไม่มีลิงก์ Affiliate แบบ https, คะแนนต่ำกว่า 4.5 ดาว (AliExpress ต่ำกว่า 90%), หรือขายได้น้อยกว่า 30 ชิ้น
   - ที่ตั้งขั้นต่ำยอดขายไว้ ก็เพื่อไม่ให้ของที่ได้ 5 ดาวจากรีวิวแค่ 2–3 อันขึ้นไปอยู่บนสุด
4. **เรียงลำดับ**: รีวิวสูงสุดก่อน (5.0 → 4.9 → …) ถ้าคะแนนเท่ากันให้ยอดขายมากกว่าขึ้นก่อน เก็บไว้ 8 อันดับแรกต่อคำค้น
5. **ในแอป**: ชนิดปลาหรือหมึกแต่ละตัวจะแสดงสินค้าที่ตรงกับชนิดนั้นหรืออุปกรณ์ของมันก่อน ตามด้วยของทั่วไป แต่ละกลุ่มเรียงตามรีวิว แล้วตามยอดขาย แต่ละรายการแสดงเป็น "⭐4.9 · ขายแล้ว 5k · Shopee"
6. **แอดมิน**: บล็อกหรือเลิกบล็อกสินค้าได้ (สินค้าที่บล็อกแล้วจะยังถูกบล็อกอยู่แม้ระบบรีเฟรช) แก้คำค้นได้ และกด "ดึงตอนนี้" ได้
   - สินค้าที่หลุดจากอันดับจะถูกซ่อน ไม่ถูกลบ ประวัติคลิกจึงยังอยู่

## เปิดใช้งาน (ทำครั้งเดียว)
1. สมัครโปรแกรม Affiliate ของแต่ละเครือข่ายแล้วขอสิทธิ์ใช้ API
   - **Shopee Affiliate Open API**: สมัครที่ affiliate.shopee.co.th แล้วขอ Open API ได้ App ID และ Secret (ใช้เวลาอนุมัติประมาณ 5–15 วัน)
   - **AliExpress**: สมัคร AliExpress Portals แล้วสร้างแอปที่ AliExpress Open Platform ได้ App Key, App Secret และ Tracking ID
2. ไปที่ Cloudflare → Worker seascout → Settings → Variables and Secrets แล้วเพิ่มค่าต่อไปนี้ (ค่าที่ลงท้าย _SECRET ให้ตั้งเป็นแบบ Secret):
   - `SHOPEE_AFF_APP_ID`, `SHOPEE_AFF_SECRET`, `SHOPEE_AFF_ENDPOINT` (URL ของประเทศไทย ตามเอกสาร Shopee), `SHOPEE_AFF_COUNTRY`=TH, `SHOPEE_AFF_CURRENCY`=THB
   - `ALIEXPRESS_APP_KEY`, `ALIEXPRESS_APP_SECRET`, `ALIEXPRESS_TRACKING_ID`
3. ไปที่แอดมิน → สินค้าอัตโนมัติ แล้วกด "ดึง" ที่คำค้น 1 ตัว ตรวจว่าชื่อ, รูป, คะแนน และยอดขายตรงกับหน้าร้านจริง จากนั้นค่อยเปิด flag `auto_shop`
   - ต้องตรวจขั้นนี้ก่อน เพราะชื่อฟิลด์ต่าง ๆ ยึดตามเอกสาร API และยังไม่เคยทดสอบกับคีย์จริง

## ภาระต่อแผนฟรี
- ต่อวัน: Cron 48 ครั้ง, เรียกเครือข่าย 48 ครั้ง, เขียน D1 ประมาณ 2,000 แถว (โควตาฟรีคือ 100,000 แถว)
- CPU ต่อรอบไม่กี่มิลลิวินาที (ส่วนใหญ่เป็นการรอเครือข่าย ซึ่งไม่นับเป็น CPU)
- ฝั่งแอป: ยังเป็นแคตตาล็อก 1 คำขอ แคชไว้ 12 ชั่วโมงเหมือนเดิม
