# Sea Scout — แอป Android (Capacitor)

เว็บแอป Sea Scout r14.15.24 ห่อเป็นแอป Android ไฟล์เว็บทั้งหมดรวมทั้งข้อมูลน้ำขึ้นลงทั่วโลกอยู่ในตัวแอป จึงคำนวณน้ำขึ้นลงได้แม้ไม่มีเน็ต

## สิ่งที่ได้เพิ่มเมื่อเทียบกับเว็บ
- GPS ทำงานต่อเมื่อปิดจอหรือสลับไปแอปอื่น (Foreground service) ระหว่างนำทาง เฝ้าสมอ หรือบันทึกเส้นทาง จะมีการแจ้งเตือนค้างไว้ว่า "Sea Scout กำลังใช้ GPS"
- เสียงเตือนใช้ช่องแจ้งเตือนความสำคัญสูงของ Android ดังและสั่นแม้แอปอยู่เบื้องหลัง
- ปุ่มย้อนกลับไม่ปิดแอปทิ้งระหว่างนำทาง แต่ย่อแอปไว้
- เปิดได้ไม่ต้องรอโหลดไลบรารีหรือข้อมูลน้ำขึ้นลงจากเน็ต

## วิธี build APK ฟรี (ไม่ต้องลงโปรแกรม)
1. สมัคร GitHub (ฟรี) แล้วสร้าง repository ใหม่ แบบ Private ได้
2. อัปโหลดทั้งโฟลเดอร์นี้ขึ้น repository
   - เว็บ GitHub ลากวางได้ครั้งละ 100 ไฟล์ แต่โปรเจกต์นี้มีประมาณ 640 ไฟล์ แนะนำใช้ **GitHub Desktop** (ฟรี): File → Add local repository → เลือกโฟลเดอร์นี้ → Publish repository
3. ไปที่แท็บ **Actions** จะเห็นงาน "Build Android (Sea Scout)" ทำงานเอง ใช้เวลาประมาณ 5–10 นาที
4. เมื่อขึ้นเครื่องหมายถูกสีเขียว กดเข้าไป แล้วดาวน์โหลด **SeaScout-debug-apk** ที่อยู่ด้านล่าง
5. แตก zip แล้วส่งไฟล์ `app-debug.apk` เข้ามือถือ เปิดติดตั้ง (ต้องอนุญาต "ติดตั้งจากแหล่งที่ไม่รู้จัก")

repo แบบ Private ได้เวลา build ฟรีเดือนละ 2,000 นาที ซึ่ง build ได้ประมาณ 200 ครั้ง

## ทางเลือก: build ในคอมพิวเตอร์
ติดตั้ง Node 22 และ Android Studio แล้วรันคำสั่ง:
`npm ci` → `npx cap sync android` → เปิดโฟลเดอร์ `android` ใน Android Studio → Run

## อัปเดตเว็บแอปในตัว APK
นำ `index.html` เวอร์ชันใหม่มาวางทับใน `www/` แล้ว push ขึ้น GitHub ระบบจะ build ใหม่ให้เอง

## Build สำหรับขึ้น Google Play (ทำทีหลัง)
1. สร้างกุญแจเซ็นแอป (keystore) แล้วเก็บไว้ให้ดี **ถ้าหาย จะอัปเดตแอปใน Play ไม่ได้**
2. ใส่ GitHub Secrets 4 ค่า:
   - `SEA_KEYSTORE_BASE64`: keystore ที่แปลงเป็น base64
   - `SEA_KEYSTORE_PASSWORD`
   - `SEA_KEY_ALIAS`
   - `SEA_KEY_PASSWORD`
3. build รอบถัดไปจะได้ไฟล์ `app-release.aab` สำหรับอัปโหลดขึ้น Play Console
