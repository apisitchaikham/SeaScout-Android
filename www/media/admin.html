🎬 จัดการวิดีโอ/รูปในแท็บ “วิเคราะห์”

ใส่ลิงก์ YouTube (รูปตัวอย่างดึงให้อัตโนมัติ) ลิงก์รูป หรือเว็บไซต์ใดก็ได้ ใต้ชนิดสัตว์แต่ละอันดับ (1. 2. 3. …) ในแท็บวิเคราะห์จะมี 1 บล็อก ที่ผู้ใช้เลื่อนซ้าย-ขวาดูสินค้า/วิดีโอได้หลายชิ้น (สูงสุด 12 ชิ้นต่อชนิด) แต่ละชิ้นมีรูป (หลายรูปได้) ราคา คำอธิบายอุปกรณ์ และลิงก์ร้าน แอปเลือกสื่อให้แต่ละชนิดตามลำดับ: รหัสชนิดตรงกันก่อน → ประเภทอุปกรณ์ (squid/octopus/reef/…) → กลุ่ม (pel/reef/dem…) → squid/fish → all · ใส่ราคาได้เพื่อโชว์สินค้า (ป้ายสีส้มมุมขวาบน)

  1. แก้ไขรายการด้านล่าง
  2. กด คัดลอก JSON
  3. กด เปิดไฟล์บน GitHub → ลบของเดิม → วาง → Commit changes
  4. รูปของตัวเอง: อัปโหลดไฟล์เข้าโฟลเดอร์ www/media/img/ บน GitHub (Add file → Upload files) แล้วใส่ media/img/ชื่อไฟล์.jpg
  5. ประมาณ 1–2 นาทีเว็บจะอัปเดต แอปในมือถือดึงไฟล์ใหม่เองทุก 30 นาที
